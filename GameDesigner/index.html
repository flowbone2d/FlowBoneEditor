GameDesigner

Một canvas có sẵn để trình bày art game: xếp nhiều artboard, zoom, chạy thử và xuất PNG, PDF, HTML. Bạn chỉ cần chuẩn bị art, phần tính năng không phải làm lại.

Tải về: canvas-shell.html (2,4 MB, phần editor) · build_canvas.py (công cụ đóng gói) · starter/canvas.json · starter/Main.dc.html

Lưu ý: mở thẳng canvas-shell.html chỉ thấy trang trống vì nó chưa có art. Hãy gắn art vào bằng một trong các cách dưới đây.

Cách 1: Đóng gói bằng Python

Cần Python 3, không phải cài thêm thư viện.

  1. Tải editor và công cụ đóng gói vào cùng một thư mục: 
    curl -O https://flowbone2d.github.io/FlowBoneEditor/GameDesigner/canvas-shell.html
curl -O https://flowbone2d.github.io/FlowBoneEditor/GameDesigner/build_canvas.py
  2. Tạo thư mục art từ mẫu: 
    mkdir my-art
curl -o my-art/canvas.json https://flowbone2d.github.io/FlowBoneEditor/GameDesigner/starter/canvas.json
curl -o my-art/Main.dc.html https://flowbone2d.github.io/FlowBoneEditor/GameDesigner/starter/Main.dc.html
  3. Đóng gói: 
    python3 build_canvas.py my-art my-art.html --title "My Art"
  4. Mở my-art.html trong trình duyệt. Mỗi lần sửa art thì chạy lại lệnh ở bước 3.

Cách 2: Load từ GitHub Pages

Lưu đoạn dưới thành một file HTML, đặt cạnh thư mục art/ trên website của bạn. Khi mở, trang tải editor từ GitHub Pages rồi gắn art vào.

<!doctype html>
<meta charset="utf-8">
<title>Đang tải...</title>
<script>
const SHELL = 'https://flowbone2d.github.io/FlowBoneEditor/GameDesigner/canvas-shell.html';
const TITLE = 'My Art';
const BASE  = 'art/';
// Liệt kê đủ mọi file trong thư mục art, kể cả ảnh.
const FILES = ['canvas.json', 'Main.dc.html'];

const isText = n => /\.(html|json|css|js|svg|md|txt)$/i.test(n);
const toBase64 = buf => {
  let s = '';
  new Uint8Array(buf).forEach(b => s += String.fromCharCode(b));
  return btoa(s);
};
const read = async n => {
  const r = await fetch(BASE + n);
  if (!r.ok) throw new Error('Thiếu file: ' + n);
  return isText(n) ? r.text() : toBase64(await r.arrayBuffer());
};
(async () => {
  const [shell, ...data] = await Promise.all([
    fetch(SHELL).then(r => r.text()),
    ...FILES.map(read),
  ]);
  const files = Object.fromEntries(FILES.map((n, i) => [n, data[i]]));
  const doc = JSON.stringify({ title: TITLE, content: { files }, comments: [] })
    .replaceAll('<', '\\u003c');
  const tag = 'id="appifact-doc">';
  const start = shell.indexOf(tag) + tag.length;
  const end = shell.indexOf('</scr' + 'ipt>', start);
  document.open();
  document.write(shell.slice(0, start) + doc + shell.slice(end));
  document.close();
  document.title = TITLE;
})();
</script>

Trang này phải chạy qua http:// hoặc https://. Mở bằng file:// sẽ không tải được art. Để thử trên máy:

python3 -m http.server 8000

Claude Artifact

Artifact trên claude.ai chỉ tải script từ một số CDN cho phép, nên không import được editor từ GitHub Pages. Thay vào đó, hãy nhờ Claude tạo canvas từ Design type: canvas đó đã có editor riêng và còn lưu được chỉnh sửa.

Design type dùng định dạng canvas.json mới và cách upload ảnh khác, nên thư mục art ở đây không chép thẳng sang được.

Thư mục art

Mọi file nằm ngay trong thư mục art. Công cụ đóng gói không đọc thư mục con.

my-art/
  canvas.json       bố cục canvas
  Main.dc.html      một artboard
  Shop.dc.html      artboard khác
  coin.png          ảnh dùng trong artboard

canvas.json

{
  "artboards": [
    { "file": "Main.dc.html", "title": "Main", "page": "page-1",
      "x": 0, "y": 0, "w": 960, "h": 540, "is_interactive": true },
    { "file": "Shop.dc.html", "title": "Shop", "page": "page-1",
      "x": 1060, "y": 0, "w": 960, "h": 540 }
  ],
  "annotations": [
    { "id": "note-1", "page": "page-1", "x": 0, "y": -150, "w": 400, "text": "Ghi chú" }
  ],
  "launch": { "view": "canvas", "page": "page-1" },
  "pages": [ { "id": "page-1", "name": "Page 1" } ]
}
TrườngÝ nghĩa
artboardsDanh sách artboard. x, y là vị trí trên canvas, w, h là kích thước khung.
is_interactiveĐánh dấu artboard có nút hoặc link hoạt động.
annotationsGhi chú dán trên canvas. Để [] nếu không dùng.
pagesCác trang của canvas. Mỗi artboard thuộc một trang qua page.
launchTrang hiện ra khi mở. Luôn khai báo trường này.

Viết artboard

Mỗi artboard là một file .dc.html. Giữ nguyên dòng support.js, phần tử gốc có kích thước đúng bằng w và h trong canvas.json.

<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <script src="./support.js"></script>
</head>
<body>
<x-dc>
<helmet>
  <style>
body{margin:0;overflow:hidden}
  </style>
</helmet>
<div style="width: 960px; height: 540px; background: #1c1207; color: #f6e8ca">
  <h1>Shop</h1>
  <img src="coin.png" style="width: 96px">
  <a href="Main.dc.html">Quay lại</a>
</div>
</x-dc>
<script type="text/x-dc" data-dc-script data-props='{"$preview":{"width":960,"height":540}}'>
class Component extends DCLogic {
  renderVals() { return {}; }
}
</script>
</body>
</html>
  • Ảnh: ghi đúng tên file, ví dụ src="coin.png", và đặt ảnh trong thư mục art.
  • Chuyển màn hình: dùng <a href="Shop.dc.html">. Link hoạt động trong chế độ Play.
  • Kích thước: $preview phải khớp w và h của artboard.

Dùng canvas

NútViệc làm được
PagesChuyển giữa các trang của canvas.
ZoomPhóng to, thu nhỏ canvas.
Play (trên artboard)Mở artboard toàn màn hình. Bấm Back to canvas để quay lại.
Export (trên artboard)Xuất PNG 1×, PNG 2×, PDF, HTML (.zip), hoặc gộp mọi artboard thành một PDF.

Giới hạn

  • Chỉ xem, không lưu: ngoài claude.ai, canvas ở chế độ Read-only. Muốn đổi nội dung thì sửa file art rồi đóng gói hoặc tải lại trang.
  • Cách 2 cần mạng: nếu GitHub Pages không truy cập được thì trang không mở được. Dùng cách 1 khi cần chạy offline.
  • Phiên bản: cách 2 luôn dùng file editor mới nhất trên Pages. Cách 1 giữ nguyên bản đã đóng gói.
